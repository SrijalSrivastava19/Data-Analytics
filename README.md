# 🚀 Projects

## 1. Automated Data Pipeline & Forensic Log Analyzer

**Sprint 1**

A Python-based data pipeline designed to process server log files in `.txt` and `.json` formats.

The project focuses on building a crash-resistant data processing pipeline that can:

- Scan and filter log files.
- Ignore hidden and temporary files.
- Parse JSON and TXT log files.
- Handle corrupted files using exception handling.
- Implement Object-Oriented Programming using a `DataParser` class.
- Identify server errors such as HTTP 5xx responses.
- Prepare clean data for further analysis.
- Quarantine corrupted log files.

### Technologies Used

- Python
- Google Colab
- JSON
- File Handling
- Exception Handling
- Object-Oriented Programming
- Git & GitHub

## 2. E-Commerce Data Analysis & Visualization

**Sprint 2**

A Python-based data analysis project focused on collecting, cleaning, processing, and analyzing e-commerce product data.

The project uses web scraping and exploratory data analysis techniques to transform raw product information into a structured dataset.

### Key Tasks

- **Web Scraping:** Extract product names, prices, and ratings using Requests and BeautifulSoup.
- **Dataset Auditing:** Load datasets and inspect their structure and missing values.
- **Data Cleaning:** Clean currency values and convert columns into appropriate data types.
- **Outlier Detection:** Apply the Interquartile Range (IQR) method to identify unusual product prices.
- **Exploratory Data Analysis:** Remove duplicate records, standardize brand names, and perform category-wise analysis.
- **Correlation Analysis:** Examine relationships between product prices, ratings, and review counts.
- **Data Visualization:** Generate histograms, boxplots, and correlation heatmaps.
- **Data Export:** Export the cleaned dataset into CSV format for downstream SQL and Power BI analysis.

### Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Requests
- BeautifulSoup
- Matplotlib
- Seaborn
