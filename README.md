## 🚀 Projects

### 1. Automated Data Pipeline & Forensic Log Analyzer

**Sprint 1**

A Python-based data pipeline designed to process server log files in `.txt` and `.json` formats.

The project focuses on building a **crash-resistant data processing pipeline** that can:

- Scan and filter log files
- Ignore hidden and temporary files
- Parse JSON and TXT log files
- Handle corrupted files safely using exception handling
- Use Object-Oriented Programming with a `DataParser` class
- Identify server errors such as HTTP `5xx` responses
- Prepare clean data for further analysis
- Quarantine corrupted log files
